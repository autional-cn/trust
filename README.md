# Autional 信任中心

**域名**：[trust.autional.cn](https://trust.autional.cn)
**技术栈**：Vite + React 19 + TypeScript + Tailwind CSS
**仓库**：[github.com/autional-cn/trust](https://github.com/autional-cn/trust)

安全实践、数据保护与合规建设进展说明。

## 开发

```bash
pnpm install
pnpm dev      # http://localhost:13109
pnpm build    # 构建产物：apps/trust-center/dist/
pnpm test     # Vitest 单元测试
```

## 部署

推送至 `main` 分支后由 Vercel 自动部署。
